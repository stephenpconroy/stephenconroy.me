# stephenconroy.me

The personal website of Stephen P. Conroy, international school leader.

A static site with no build step: `index.html`, `assets/` (styles, the painted panorama in `assets/js/scene.js`, self-hosted fonts with their licences), the CV at `cv/Stephen-Conroy-CV.pdf`, and `404.html`. Hosted on GitHub Pages at https://stephenconroy.me.

Fonts: Newsreader, Geist and Geist Mono, under the SIL Open Font License (see `assets/fonts/`).
